# زرپین — پروتوتایپ

**لینک تست روی گوشی:** https://siavashghanbari.github.io/Zarpin/

- `index.html` — خود اپ (پروتوتایپ زرپین). فونت و تصویرها داخل همین فایل هستند.
- `zarpin-api-docs.html` — مستندات API (از صفحه‌ی «مدیریت API» داخل اپ هم باز می‌شود).
- `راهنما.txt` — راهنمای تست.

## نکات تست
- همه‌ی کدهای تأیید `123456` است؛ با زدن روی بنر پیامک، کد خودش پر می‌شود.
- پنل تست (ورود، موجودی، نتیجه‌ی پرداخت، پرش به صفحه‌ها و …) زیر گوشی است.
- همه‌ی داده‌ها نمونه هستند و هیچ تراکنش واقعی انجام نمی‌شود.

## وام با وثیقه‌ی طلا (جدید)
ورودی: کاشی «وام» در صفحه‌ی اصلی (هر دو نسخه).
مسیر: ماشین‌حساب ← جزئیات وام ← پیش‌نیازها و رضایت ← قفل وثیقه (خرید کسری با همان فلوی خرید + کد تأیید) ← ونسی (صفحه‌ی شبیه‌سازی) ← بررسی و واریز بانک.
- پنل تست: «وام»، «پاسخ بانک به وام»، «قیمت لحظه‌ی قفل وثیقه»، «سلامت وثیقه‌ی وام» و گروه «وام با وثیقه‌ی طلا» در «پرش به صفحه».
- در صفحه‌ی جزئیات وام، دکمه‌های خط‌چین «تست:» وضعیت را جلو می‌برند (پایان مهلت، پاسخ بانک، پرداخت‌نشدن قسط).
- عددهای تعیین‌نشده در سند (هزینه‌ی عملیات ونسی، کارمزد زرپین، سود وام بانک گردشگری) با «—» نمایش داده می‌شوند.
- همه‌ی پیامک‌های وام در «فهرست همه‌ی پیامک‌ها» هستند.

## به‌روزرسانی
فایل جدید را با نام `index.html` جایگزین کنید و commit کنید؛ چند دقیقه بعد لینک بالا به‌روز می‌شود.
